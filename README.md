# 💱 Currency Converter JS

🌐 Live Demo: (Add your live link here)

A responsive and interactive Currency Converter web application built using HTML, CSS, and JavaScript. This project allows users to convert currencies in real time, swap currencies, and display country flags dynamically using APIs.

---

## 🚀 Features

- 💱 Real-time currency conversion
- 🔄 Swap currencies functionality
- 🌍 Multiple currency support
- 🚩 Dynamic country flags using API
- 📱 Responsive design
- 🎨 Modern and clean UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Currency Exchange API
- Flags API

---

## 📂 Project Structure

- `index.html`
- `style.css`
- `script.js`

---

## 📌 Purpose of Project

This project was created to practice API integration, DOM manipulation, event handling, and responsive UI design using JavaScript.
